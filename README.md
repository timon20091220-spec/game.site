# Space War / Neon Rift - v461 Stable

이 ZIP은 GitHub Pages 사이트 업로드용 파일입니다.

## 포함 파일
- `index.html` : 게임 실행 파일
- `README.md` : 설명 파일
- `upload_guide.txt` : 업로드 방법
- `.nojekyll` : GitHub Pages에서 파일을 그대로 배포하기 위한 설정 파일
- `version.txt` : 버전 정보

## v461 안정판 기준
- PC/태블릿 선택창 안정화
- 모바일 독립 처리
- 조이스틱 고정 위치 + 화면 빈 곳 이동 입력
- DASH 버튼 분리
- 설정 버튼 클릭 가능
- 설정 닫은 뒤 컨트롤 복구
- 로비/선택창에서 조이스틱/DASH 숨김
