GitHub Pages 업로드 방법

1. 이 ZIP 파일을 압축 해제합니다.
2. 안에 있는 파일들을 전부 GitHub 저장소에 업로드합니다.
   - index.html
   - README.md
   - upload_guide.txt
   - .nojekyll
   - version.txt
3. GitHub Pages가 켜져 있으면 사이트 주소로 접속합니다.
4. 기존 파일이 있으면 index.html을 덮어쓰기 하면 됩니다.

주의:
- index.html 이름을 바꾸면 사이트 첫 화면에서 자동 실행되지 않을 수 있습니다.
- 압축 파일 자체를 올리는 것이 아니라, 압축을 푼 안쪽 파일들을 올려야 합니다.
